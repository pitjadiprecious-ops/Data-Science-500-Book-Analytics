### About
This project is part of my DS500 coursework. It involves scraping data from books.toscrape.com and analysing it to understand book pricing and ratings.
I used Python to collect 1000 books, cleaned the data, and then explored it visually. Finally, I trained a machine learning model to predict prices.

This project focuses on collecting and analysing book data from the Books to Scrape website. Python is used to collect, clean and explore the data through graphs and visualisations. A linear regression model is also developed to estimate book prices. The aim of this project is to understand book prices, ratings and availability using data science techniques.

### What I Did
1. Scraped 1000 books using BeautifulSoup
2. Cleaned the dataset (removed duplicates, fixed price format)
3. Created visualizations for price, rating and availability
4. Built a Linear Regression model

### Tools
Python | Pandas | Matplotlib | Scikit-Learn
